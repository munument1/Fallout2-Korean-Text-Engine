# Korean Text Engine v1.2.5 — Olympus 2207 설치 및 튜토리얼

- Olympus 2207 1.2a의 원본 Extended sfall 설정을 유지하면서 한국어 실행 파일의 CRC를 등록합니다.
- 올림푸스의 고해상도 패치와 함께 실행해도 한글 글꼴을 불러옵니다.
- 시작 튜토리얼 팝업의 한글이 깨지고 긴 안내문이 양옆에서 잘리는 문제를 수정합니다.

## 설치 및 업데이트

1. 게임을 종료합니다.
2. [Olympus 2207 한국어 번역 ZIP](https://github.com/munument1/Fallout2-Olympus2207-KR/releases/latest)을 **olympus.exe**가 있는 폴더에 풉니다.
3. 기존 독립형 엔진을 설치했다면 설치기의 복구 기능을 먼저 실행합니다. 구형 KR1.1이 sfall을 덮어쓴 설치본은 원본 **olympus.exe**, **ddraw.dll**, **ddraw.ini** 및 고해상도 패치 구성을 복구합니다.
4. **Fallout2-Korean-Native-Setup.exe**에서 게임 폴더를 지정한 뒤 **olympus.exe**로 실행합니다.

## 검증 범위

원본 Olympus 2207 1.2에 1.2a 패치를 적용한 설치본에서 메인 메뉴, 캐릭터 선택, 첫 대화 및 시작 안내창 두 개를 확인했습니다. 튜토리얼 건너뛰기 안내가 여러 줄로 표시되며 문장 끝까지 읽을 수 있습니다.

이전 버전 변경 사항은 [v1.2.4 릴리즈 노트](RELEASE_NOTES_V1_2_4.md)에 있습니다.
