# Fallout 2 한국어 출력 엔진 v1.1.0-beta.1 (시험판)

> **주의: 테스트 전용 프리릴리즈입니다. 게임이 정상 작동한다고 검증된 정식판이 아닙니다.**
>
> 기존 정식판 `v1.0.0`은 변경하지 않습니다. 게임·모드를 **별도로 복사한 테스트 폴더**에만 설치하세요.

## 이번 시험판의 핵심 변경

- **공식 또는 기존 sfall의 `ddraw.dll`을 교체하지 않습니다.**
- 기본 설치에서는 **`ddraw.ini`를 읽기만 하고 절대 수정하지 않습니다.**
- 기존 sfall이 설치되어 있고, 수정 한국어 EXE의 `ExtraCRC`가 등록되어 있지 않다면 임의로 설치를 강행하지 않습니다. 이때 **고급 설정 → sfall 호환 설정 적용**을 명시적으로 선택해야 합니다.
- sfall이 없는 순정 Fallout 2 복사본에도 설치할 수 있도록 분리했습니다. **실제 게임 구동 검증은 아직 완료되지 않았습니다.**
- 게임·모드 EXE의 해시를 엄격하게 확인하고, 설치 전 파일을 백업해 복구할 수 있습니다.
- 확인되지 않은 다른 sfall 빌드는 DLL·설정 구조만 검사하며, 실행 호환성은 **미검증**입니다.

## 설치 방법 (테스트 권장: 순정 Fallout 2 → RPU 순)

1. 원본 게임 폴더를 **다른 위치에 복사**합니다. 원래 설치본에 적용하지 마세요.
2. 사용할 게임/모드가 요구하는 sfall이 있다면 **그 버전을 유지**합니다. 기존 `ddraw.dll`을 덮어쓰지 마세요.
3. 아래 첨부 `Fallout2-Korean-Text-Engine-Setup.exe`를 실행합니다.
4. 게임/모드 폴더와 사용자가 별도로 확보한 검증된 `FO2_UPU_CHT_v34` CJK 파일 폴더(`Fallout2.exe`, `fallout2font.dll`)를 지정합니다.
5. **기존 공식 sfall 4.5.1로 시험하는 경우:** 한국어 EXE CRC가 기본 허용 목록에 없으므로, **고급 설정 → sfall 호환 설정 적용**을 켜야 합니다. 이 경우에는 예외적으로 기존 `ddraw.ini`가 수정되며 설치 전 버전이 백업됩니다.
6. 설치 후 **별도 한국어 번역 파일**을 해당 게임/모드에 적용하고 게임 실행을 확인합니다.
7. 메뉴·대화·아이템 설명·전투 메시지·저장/불러오기를 검사하고, 설치기 **설치 전 상태로 복구**까지 시험합니다.

## CRC 참고 (현재 고정 빌드 기준)

| 대상 게임/모드 | 한국어 EXE CRC32C |
| --- | --- |
| Fallout 2 원본 / RPU / Et Tu / Resurrection | `0xFCDC75E0` |
| Sonora | `0xFF51969F` |
| Nevada Extended | `0xE5BF456F` |
| Olympus 2207 | `0xE81550F3` |
| Sonora 개발판 | `0xFC345277` |

**한국어 EXE CRC가 공식 sfall의 허용 목록에 추가됐다는 뜻은 아닙니다.** 공식 sfall 팀에 등록을 제안하는 작업은 [PR #6](https://github.com/munument1/Fallout2-Korean-Text-Engine/pull/6)에 별도 준비되어 있습니다. 업스트림 수락 전까지는 `ExtraCRC` 없이 기존 sfall과 정상 작동한다고 안내하지 마세요.

## 배포 내용

- `Fallout2-Korean-Text-Engine-Setup.exe` — Windows GUI 설치기
- `korean-text-engine.zip` — 개발자용 엔진 패키지
- `SHA256SUMS.txt` — 위 두 파일의 해시

빌드는 GitHub Actions의 유닛 테스트와 Windows 패키징 자체 검사 후 배포됩니다. **실제 게임 플레이를 대신하는 검증은 아닙니다.** 기존 sfall 실행을 직접 수정하는 프로그램은 배포하지 않습니다.
