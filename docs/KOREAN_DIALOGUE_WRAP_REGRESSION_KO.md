# Fallout 2 독립형 한글 엔진: 한국어 대화문 무손실 검사

검사일: 2026-10-17

## 목적

이전 캐릭터 설명 카드의 12줄 강제 제한은 긴 문장을 조용히 잃게 만들 수 있어 제거했습니다.
대화창 및 선택지에 같은 종류의 내용 손실이 없도록 실제 사용자 보유 RPU 한국어 대화를
독립형 글꼴 DLL의 줄바꿈 함수에 공급해 검사했습니다.

## 소스 및 범위

- 소스: 사용자 소유 로컬 RPU 한국어 번역의 mods/rpu/text/korean/dialog/*.msg
- 소스 파일/게임 저작물은 이 저장소에 복사하지 않았습니다.
- 테스트 프로그램: tests/dialog_wrap_probe.cpp
- 실행 환경: Windows x86, 독립적으로 컴파일한 fallout2font.dll
- 별도로 tests/generate_dialog_fixture.py가 만든 **자체 제작 CP949 대화문 320개**를
  자동 빌드에서 매번 검사하도록 설정했습니다.

검사한 항목:

1. MSG 구조로 추출한 대화문 12,000개 (316개 파일).
2. 글꼴 101로 텍스트 최대 폭 **175px, 280px** 양쪽의 줄바꿈 수행.
3. 바이트 오프셋의 증가 순서, 최초 오프셋 0 및 마지막 오프셋 == 원문 바이트 길이.
4. 각각의 줄에서 **유효한 CP949 문자 경계** 유지.
5. 일반 줄바꿈 함수와 대화용 호출자 경로의 오프셋 일치.

결과: 총 **12,000개 성공, 오류 0건**.
검사된 문자열 최대 길이는 **570바이트**, 좁은 폭 기준 최대 **18줄**.
이 12,000개 메시지에서 CP949 변환 불가 또는 지나치게 긴 문장으로 건너뛴 항목은 **0개**.

실행 로그:

    files=316 checked=12000 widths=175,280 max_lines=18 max_bytes=570 invalid_cp949_skipped=0 oversized_skipped=0 failures=0

## 실게임 확인과 구분

위 검사는 **DLL이 문자열을 잃지 않고 줄바꿈하는지** 확인하는 자동 회귀 시험입니다.
게임 내에서 실제 NPC와 대화해 18줄짜리 답변을 화면으로 확인한 시험은 아닙니다.

게임의 UI에는 대화 답변 창, 선택지 영역, 스크롤, 줄간격, 원본의 영역 높이 같은 별도
제약이 있습니다. 따라서 **이번 결과만으로 18줄 대화가 모두 화면에 보인다거나
모든 선택지가 안전하게 표시된다고 주장하면 안 됩니다.**

남은 검증:

- NPC 실제 대화에서 길이가 긴 답변과 3개 이상 선택지가 있는 대화 재현
- 마우스 휠/키보드 스크롤, 창에 못 들어간 답변과 선택지가 사라지는지 점검
- 선택지 선택 후 게임 진행과 저장·불러오기 안정성 검증
- CP949 대화 파일 이외의 스크립트/동적 대화 문자열 및 다른 언어 혼합 처리

## 실행 방법

본인에게 사용 권한이 있는 한국어 대화 파일 디렉터리를 전달합니다.

    dialog_wrap_probe.exe <own-native-font.dll> <owned-korean-dialog-folder> 12000

실게임 EXE나 제3자 CJK 코드는 검사 도구에 포함되지 않습니다.
