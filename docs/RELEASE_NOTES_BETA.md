# Fallout 2 Korean Text Engine — v0.1.0-beta

**Windows GUI 설치기 첫 시험판입니다.** 일반 사용자용 설치 경험을 단순화하기 위해 제작했습니다.

### 포함 사항
- Windows용 `Fallout2-Korean-Text-Engine-Setup.exe` (Python 별도 설치 불필요)
- 검증된 게임 EXE에 대한 프로필 감지 및 모드 선택
- 설치 전 해시 검사, 원본 백업 및 복구
- 기존 `korean-text-engine.zip` 개발자용 패키지

### 주의 사항
- **베타 버전:** 각 게임의 전체 플레이 또는 모든 Windows PC에서의 작동이 검증된 것은 아닙니다.
- 게임 EXE, 공식 sfall `ddraw.dll`, 기존 CJK EXE/DLL, 번역 데이터는 **포함하지 않습니다.**
- 해당 모드의 검증된 버전, 공식 sfall 4.5.1, 사용자 보유 CJK 원본 파일이 필요합니다.
- 게임 원본 Steam 폴더가 아닌 **복사본**에만 설치하세요.
- 게임별 번역 ZIP은 별도로 적용해야 합니다.
- 설치 프로그램은 서명되지 않았습니다. Windows에서 다운로드 및 실행 확인 메시지가 표시될 수 있습니다.

문제가 있으면 게임/모드 이름, 설치 대상 버전, 출력된 오류 메시지를 저장소 Issue로 알려 주세요.
