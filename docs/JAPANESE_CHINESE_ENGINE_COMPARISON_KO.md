두 외국어판은 동일한 중국어 CJK 폰트 DLL을 사용합니다. 일본어/중국어 EXE는 모두 1,192,448바이트이며 기존 게임 코드 수정과 .topo0 확장을 공유하지만 완전히 같은 파일은 아닙니다. 원본 대비 변경 구간(PE 헤더 포함)은 일본어 약 42곳, 중국어 약 37곳, 두 패치 사이에는 33개 구간 차이가 있습니다.

## 줄바꿈 관련 구체적 차이

- 양쪽 패치는 원본 wordWrap 함수 주소 0x4BC6F0에서 0x6F01E0으로 점프합니다.
- 공통 호출 코드는 기존 게임 레지스터 인자를 바꿔 CJK DLL 내의 글자 처리 함수로 전달합니다.
- 둘 모두 캐릭터 카드 줄바꿈 호출 0x43ACFC와 바로 뒤 분기 구조는 원본과 같습니다. 함수 교체 자체가 카드 높이를 확장하는 방식은 아닙니다.
- CJK EXE의 문자 경계 처리에는 언어별 차이가 있습니다. 예컨대 0x6F0280 부근 및 0x43AD3F, 0x43DD8B에는 서로 다른 문자열 보정 경로가 있습니다. 어느 언어판이 더 우수하다는 결론은 아니며, 일본어 Shift-JIS 및 중국어 Big5 처리 차이에 가깝습니다.

## 기존 일본어판도 해결하지 못한 문제

Fallout2jp190915 공식 일본어 위키에는 특정 대화에서 영문판보다 표시 가능한 줄이 하나 적어 대화 종료 선택지가 가려지는 문제가 알려진 문제로 기재돼 있습니다.

- 일본어 패치: https://w.atwiki.jp/fallout2jap/pages/37.html
- 일본어 설치 안내: https://w.atwiki.jp/fallout2jap/pages/4.html
- 중국어 패치: https://github.com/NovaRain/FO2_UPU_TChinese

즉 중국어·일본어판을 모든 UI 레이아웃 문제가 해결된 레퍼런스로 여기면 안 됩니다.

## 우리 엔진에 적용할 점

1. CP949 2바이트 글자 경계를 보존하고 GDI로 실측한 픽셀 폭에 맞춰 줄바꿈하는 자체 방식 유지.
2. 캐릭터 설명 카드의 12줄 제한은 임시 안전장치이며 끝부분을 잃습니다. 최종적으로 카드 내용의 **스크롤 또는 여러 페이지 전환**을 구현해야 합니다.
3. 특히 게임 진행을 막을 수 있는 **대화 선택지**는 단순 잘림으로 대응하지 않고 전체 선택지가 나타나도록 별도 표시·스크롤을 검증해야 합니다.
4. 일본어 Adjust=3이나 중국어 BUTTON 20을 그대로 적용하지 않습니다. 한글 폰트 실제 높이, line-height 보고 값, UI 영역 높이, 표시 줄 수를 함께 조정해야 합니다.
5. 중국어 Big5 및 일본어 Shift-JIS의 DBCS 처리 코드를 한국어 CP949에 그대로 적용하지 않습니다. CodePage=949와 Windows 유효 문자 검사를 유지합니다.
6. 해당 바이너리의 후킹 명세는 참고하되 구현 코드는 독자적으로 유지합니다.

## 아직 확인하지 못한 것

세 언어판을 동일 해상도·동일 길이의 번역으로 실행한 화면끼리 직접 비교한 결과는 아닙니다. 기존 일본어·중국어판에서 캐릭터 설명이 정확히 몇 줄까지 들어가는지 확정할 수 없습니다. 여기 기록한 확정 사항은 로컬 바이너리/설정 파일 분석 및 공개 문제 기록에 한합니다.
