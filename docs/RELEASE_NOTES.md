# Fallout 2 한국어 출력 엔진 v1.0.0

**Windows 정식 배포판**입니다. 일반 사용자도 Python이나 명령어 입력 없이 설치할 수 있도록 Windows 설치 프로그램을 제공합니다.

## 사용 방법

1. 별도 복사한 Fallout 2 또는 지원 모드의 게임 폴더를 준비합니다. **공식 sfall 4.5.1**이 설치되어 있어야 합니다.
2. 설치기를 실행하여 **게임 폴더**와 별도로 확보한 **FO2_UPU_CHT_v34 CJK 원본 파일 폴더**를 선택합니다.
3. **설치하기**를 누른 다음, 해당 모드의 한국어 번역 패치를 별도로 적용합니다.

모드별 실행 파일을 인식하고 정확한 파일 해시를 검사합니다. 동일한 실행 파일을 여러 모드가 공유하는 경우에는 게임 종류를 선택하도록 안내합니다. 원본 Fallout 2 US 1.02d 실행 파일이 필요한 일부 모드에서는 해당 파일을 추가로 선택해야 합니다.

## 주요 기능

- 한글 출력, 글꼴 및 줄바꿈 지원
- 공식 sfall DLL을 변경하지 않고 설치
- 기존 파일 자동 백업 및 설치 전 상태로 복구
- 호환 파일 해시 검사 및 미검증 실행 파일 거부
- 어려운 설정을 고급 메뉴로 분리한 간편 Windows 설치기

## 지원 대상으로 검사한 게임

Fallout 2 US 1.02d, RPU 2.4.34, Fallout Et Tu 2.0.3911, Fallout Sonora(클래식/검증된 개발본), Fallout Nevada Extended, Olympus 2207 1.2, Fallout 1.5 Resurrection English 1.5 + KR 1.1.

지원 범위는 **지정된 게임/모드 버전 및 해시**에 한합니다. 기존 게임 화면 검증 기록은 \`docs/validation.json\`에 있습니다. 전체 플레이 또는 모든 PC 환경을 보증하는 것은 아닙니다.

## 배포 파일

- \`Fallout2-Korean-Text-Engine-Setup.exe\` — Windows 설치기
- \`korean-text-engine.zip\` — 소스 코드·명령행 도구가 포함된 개발자용 패키지
- \`SHA256SUMS.txt\` — 다운로드 파일 무결성 확인

게임 EXE, 공식 sfall DLL, 외부 CJK EXE/DLL, 번역 데이터는 포함하지 않습니다. 설치 파일은 코드 서명이 없으므로 Windows에서 실행 확인 메시지가 표시될 수 있습니다.

문제 제보는 저장소 Issues에 게임 버전과 오류 메시지를 남겨 주세요.
